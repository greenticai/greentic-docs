### `greentic-start start`

```text
Usage: greentic-start start [OPTIONS]

Options:
      --bundle <BUNDLE>
          
      --locale <LOCALE>
          
      --env <ENV>
          Environment id whose persisted state the bundle-less boot serves. Wins over `$GREENTIC_ENV`; defaults to `local`. Ignored (with a warning) on the legacy `--bundle` / `--config` path, which has no environment concept
      --tenant <TENANT>
          
      --team <TEAM>
          
      --nats <NATS>
          [default: off] [possible values: off, on, external]
      --nats-url <NATS_URL>
          
      --config <CONFIG>
          
      --cloudflared <CLOUDFLARED>
          [default: off] [possible values: on, off]
      --cloudflared-binary <CLOUDFLARED_BINARY>
          
      --ngrok <NGROK>
          [default: off] [possible values: on, off]
      --ngrok-binary <NGROK_BINARY>
          
      --gtunnel <GTUNNEL>
          Greentic self-hosted tunnel (Cloudflare Worker + agent). Zero-config: the Worker URL, tunnel id, and secret are resolved from defaults/env [default: off] [possible values: on, off]
      --gtunnel-worker-url <GTUNNEL_WORKER_URL>
          Override the Greentic Worker tunnel base URL (else GREENTIC_TUNNEL_WORKER_URL or the built-in default)
      --gtunnel-tunnel-id <GTUNNEL_TUNNEL_ID>
          Override the tunnel id (else GREENTIC_TUNNEL_ID or a value derived from tenant/team)
      --runner-binary <RUNNER_BINARY>
          
      --restart <RESTART>
          [possible values: all, cloudflared, ngrok, gtunnel, nats, gateway, egress, subscriptions]
      --log-dir <DIR>
          
      --verbose
          
      --quiet
          
      --no-browser
          Do not open the first web UI URL in the default browser
      --open-webchat [<OPEN_WEBCHAT>]
          Open a webchat URL in the default browser after the listener starts. `--open-webchat` opens the default bundle; `--open-webchat=BUNDLE_ID` opens a specific bundle. `--no-browser` wins when both are given
      --no-updates
          Do not subscribe this runtime to its environment's update channel
      --no-auto-restart
          Do not auto-restart after a binary self-update (stage only, like P7d)
      --admin
          Enable mTLS admin API endpoint
      --admin-port <ADMIN_PORT>
          Port for the admin API endpoint [default: 8443]
      --admin-certs-dir <DIR>
          Directory containing admin TLS certs (server.crt, server.key, ca.crt)
      --admin-allowed-clients <ADMIN_ALLOWED_CLIENTS>
          Comma-separated list of allowed client CNs (empty = allow all valid certs)
  -h, --help
          Print help
```

### `greentic-start doctor`

```text
Usage: greentic-start doctor [OPTIONS] [BUNDLE]

Arguments:
  [BUNDLE]  Bundle reference or extracted bundle directory to inspect. When omitted, doctor checks the environment-store readiness of `--env` (or the resolved default env) instead

Options:
      --env <ENV>        Environment id whose store-backed runtime readiness should be checked (trust root, messaging-endpoint linkage, secret-ref resolvability). Defaults to `$GREENTIC_ENV` / `local` when no bundle is given
      --locale <LOCALE>  
      --json             Emit stable machine-readable JSON
      --strict           Promote drift/tag/cache and env-readiness warnings to errors
      --fix-hints        Include longer remediation hints in human output
      --show-info        Include informational checks in output
      --stage <STAGE>    Restrict checks to one diagnostic stage [default: all] [possible values: all, setup, cache, locks, answers, runtime, routes, provider, secrets]
  -h, --help             Print help
```
